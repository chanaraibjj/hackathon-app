# 01: Product Manager(14:10 開発開始直後)

※テーマ発表中(14:00–14:10)は聞く+メモに専念。開発開始の合図と同時にこれを貼る。

## 01-A: アイデア出し(テーマを貼るだけ)

```
これは120分ハッカソンです。テーマが発表されました。発表文は以下(一言一句そのまま):

{{テーマ発表文をそのまま貼る}}

あなたはProduct Managerです。次を一気にやってください:

テーマ理解 → アイデア10案 → 比較 → 上位3案 → MVP候補

各案の評価項目(この基準で採点・比較すること):
- テーマ適合性
- USERが明確
- PROBLEMが明確
- CORE EXPERIENCEが強い
- WOW MOMENTがある
- インパクト(欲しい・面白い・驚き)
- 実在感(実際に使われるイメージ)
- 3分デモ映え
- 120分で実装可能
- 技術リスクが低い

注意: AIがサービスに搭載されているかどうかは評価項目に入れない。

上位3案は、それぞれ以下を1行ずつで明記:
- 1 USER(誰のため?)
- 1 PROBLEM(何に困っている?)
- 1 CORE EXPERIENCE(どんな体験を届ける?)
- 1 WOW MOMENT(どこで「おお!」となる?)

最後に1位の推薦理由を2行で。
```

→ 出力を見て **14:25(IDEA FREEZE)までに1案を即決** する。

## 01-B: 技術判断(案を決めた直後に続けて貼る)

```
採用する案: {{案の名前}}

このMVPについて以下を判定してください。

AIは必要?
External APIは必要?
DBは必要?

それぞれ、「必須 / あると良い / 不要」の3段階で判定してください。

「あると良い」は原則MVPから外してください。

最も単純な技術構成を提案してください。
構成は「フロント(Next.js)→ API Route → (必要なものだけ)」の形で1枚に書き、
実装タスクを順番付きリスト(各タスクに目安時間、合計25分以内=14:50のMVP締切まで)にしてください。
```
