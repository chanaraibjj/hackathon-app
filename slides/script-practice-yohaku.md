# 3分発表台本(盛り上げ版)— そっけなさプレビュー

読み上げ目安 2:40。**太字=操作**、()=演出指示。

## 0:00–0:15 つかみ(挙手)
最初に1つだけ。今日、誰かに「わかりました。」って返信した方、手を挙げてください。
(挙がるのを待つ・2秒)……はい、ほぼ全員ですね。今日は、その7文字の話です。

## 0:15–0:40 解釈(Slide 1)
テーマは「余白」。私たちが選んだのは、メッセージの行間です。
あなたが0秒で打ったその7文字を、受け取った新人は30分かけて解読しています。
句点ひとつから、機嫌を推測して。
行間という余白のコストは、受信者だけが払っている。そして送った側は、一生気づけません。

## 0:40–0:55 プロダクト(Slide 2)
そこで、送信ボタンの手前に、相手のスマホを置きました。「そっけなさプレビュー」です。

## 0:55–1:55 ライブデモ(Slide 3 → ブラウザ。ズーム150%)
では、皆さんの「わかりました。」がどう見えているか、ご覧ください。

- **サンプル「わかりました。」をタップ/相手=新人/実行**
- 「既読がつきました」
- (内心が浮かぶ → **2秒沈黙** →)「……これが、行間です」
- 「冷たさ80点。凍えています。根拠も出ます——句点で終わる単文、感情の手がかりゼロ、7文字。占いではありません」
- 「代替案はこちら。同じ内容に、一言足すだけです」

もう1つだけ。取引先に「違います。至急直してください。」と送ると、どうなるか。

- **「違います。至急直してください。」を貼る/相手=取引先/実行**(文面は事前にメモ帳に用意)
- (内心「上長に相談すべきかもしれない」が出たら)「……炎上の3秒前です。でも大丈夫、言い換えもここまで出ます」

## 1:55–2:20 価値・WOW(Slide 2に戻る or 口頭)
体験は、貼る・選ぶ・見る。10秒です。
私たちが直すのは文章ではなく、送信者の想像力。
説教は効きません。でも、相手の画面で自分の文面が再生される「自覚」は、10秒で効きます。

## 2:20–2:40 完成度・技術(Slide 3)
これ、120分で全部動いて、公開済みです。AIもAPIもDBもゼロ。
判定根拠をそのまま見せるために、あえてルールエンジンだけで作りました。
AIは、企画・実装・デバッグの開発プロセス側でフル稼働です。

## 2:40–3:00 締め(笑いで着地)
URLは画面の通り、今この瞬間から誰でも使えます。
最後にお願いがあります。この発表のあと、私たちに「わかりました。」とだけ返すのは、やめてください。

## 盛り上げオプション(時間が読めるときだけ)

「審査員の方、最近もらってモヤッとした短文、ありませんか?」→ その場で入力して実行。

## リスク対策
- デモ前にタブを開いて1回実行しておく(初回ロード対策)。リセットして待機
- 2本目の文面はコピペ用にメモ帳へ用意(タイプミス防止)
- 通信不安時はローカル `npm run dev` を控えに起動しておく(判定は全てブラウザ内なので開きさえすれば動く)
- 沈黙は「2秒」厳守。長いと事故、短いと内心が読まれない
